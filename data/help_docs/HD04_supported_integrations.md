# Supported integrations

## Systems we connect to
We build and maintain integrations with HubSpot, Salesforce, Pipedrive, Xero, QuickBooks Online, Shopify, WooCommerce, Google Workspace, Microsoft 365, Slack, Airtable and most systems that offer a REST API or webhooks.

## Systems without an API
For older systems without an API we can work from scheduled exports (CSV or SFTP) or, as a last resort, browser automation. We will tell you the trade offs before we start.

## Adding a new integration
New integrations are scoped as a change request. Most take one to two weeks, including testing in a sandbox account.

## When an integration stops syncing
The most common cause is an expired connection, for example a password change on the connected account. Reconnect it under Integrations in the client portal. If it still fails, raise a Priority 2 ticket.
